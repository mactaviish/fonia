# contexto: o que o controlador acabou de dizer e em que frequência o piloto está
#   parked    Solo, nada pendente                         taxi-done  Solo, o piloto já taxiou até o ponto de espera
#   startup   Solo, "acionamento aprovado, chame pronto"  pushback   Solo, "autorizado pushback e acionamento"
#   taxi      Solo, "autorizado táxi para o ponto de espera da pista uno cinco"
#   handed    Solo passou o voo à Torre ("chame Torre Curitiba ...")
#   departure Torre, o piloto no ponto de espera, sem nada pendente
#   lineup    Torre, "pista uno cinco, alinhe e mantenha"
#   takeoff   Torre, "pista uno cinco, autorizado decolagem"
#   airborne  Torre, "decolado aos zero zero" (o piloto responde "ciente")
#   inbound   Torre, o piloto voltando para pouso, sem nada pendente
#   circuit   Torre, "autorizado para o circuito de tráfego, pista uno cinco, reporte perna do vento"
#   downwind  Torre, "reporte perna base"
#   base      Torre, "reporte na final"
#   landing   Torre, "pista uno cinco, pouso autorizado"
#   landed    Torre, "no solo aos zero dois, após livrar a pista chame Solo Curitiba ..."
#   vacated   Solo, o piloto acabou de livrar a pista
#   apron     Solo, "taxie para o pátio"
# esperado: o que o controlador deve fazer com o que o piloto disse (o tipo da instrução do motor). NoResponse é um cotejamento
#   aceito ou um aviso reconhecido, em silêncio; RequestReadbackCorrection é "negativo"; SayAgainRequest é "repita".
#
# Fale como num voo de verdade: natural, às vezes curto, às vezes com "bom dia" ou "ok". O indicativo é PR-FRA, dito letra por letra
# (Papa Romeo Foxtrot Romeo Alfa) ou abreviado (Foxtrot Romeo Alfa). Pista sempre dígito a dígito: UNO CINCO, nunca "quinze".
# O texto de cada linha é o que a frase diz; troque as palavras do seu jeito, desde que diga a mesma coisa.
